# 주문 · 주문 비서 · 카카오톡 알림

꽃다발 같은 **예약 주문**을 앱 안 채팅(주문 비서)으로 등록·정리·수정·삭제하고,
매일 아침 카카오톡 **‘나와의 채팅’**으로 챙길 주문을 알려줘요. (2026-11-10 추가)

## 화면 (`/orders`, 더보기 → 주문 · 주문 비서)

- **주문 비서**: 주문을 그대로 붙여 넣거나 말로 써요. 여러 줄이면 줄마다 등록.
  - `11/11 수 픽업 김포포 하치와레 꽃다발 2.5만원` → 11/11 픽업, 김포포, 하치와레 꽃다발, 25,000원
  - `11/23 월 택배 박고양 하치와레 꽃다발 2.5만원 (라넌으로 변경)` → 택배, 메모 ‘라넌으로 변경’
  - 수정 `이토끼 3만5천원으로 바꿔줘`, 완료 `박고양 택배 보냈어`, 삭제 `김포포 주문 취소`, 정리 `이번 주 주문 정리해줘`
  - 어떤 주문인지 애매하면 바꾸지 않고 되물어요. 화면엔 **서버가 실제로 바꾼 것만** ‘✓ 등록/수정/완료’로 보여요.
- **주문 목록**: 진행 중 / 완료 / 전체, 날짜순, D-day(택배 7일 안·픽업 하루 안은 노랑, 지난 건 빨강), ✓ 버튼으로 완료.
  눌러서 직접 고치기·완료·주문 취소(관리자는 취소된 주문 완전히 지우기).
- **홈 카드**: ‘챙길 주문 N건’ (7일 안 택배, 오늘·내일 픽업).

## 데이터 (`public/schema.sql` 7번, 스키마 버전 7)

- `orders`: customer, item, price, due_date(픽업일 / 택배 **받는 날**), **due_time**(픽업 시간 `time`, 선택 — 앱에선 "HH:MM"으로 다뤄요), **ship_date**(택배 **출고일**, 보내는 날, 선택 — v7, 2026-11-14), method(`pickup`/`delivery`), status(`open`/`done`/`canceled`), memo, contact, address, source_text(원문), done_at.
  RLS: 읽기·추가·수정 = 직원 이상, 지우기 = 관리자. 채팅의 ‘삭제’는 `canceled`(되살릴 수 있어요).
- `kakao_tokens`(한 줄): 카카오 access/refresh 토큰, `last_brief_on`. **서비스 키만**(anon/authenticated 권한 없음, 정책 없음).
- `app_settings`(한 줄): `brief_hour`(0~23, 기본 9). 읽기 = 직원 이상, 바꾸기 = 관리자.

## 주문 비서 동작 (`src/lib/server/orders.ts`, `POST /api/orders/chat`)

- ⚠️ **알려진 문제(2026-11-14 발견, 아직 안 고침)**: 출고일만 있고 받는 날이 없으면 받는 날(`due_date`)에 출고일을 그대로 넣어요(빠른 읽기 `orderParse.ts`, 주문 비서 AI 지시 둘 다). 화면엔 확인한 도착일처럼 보여요. 고칠 방향: ‘받는 날 미정’ 표시(예: `due_unknown`, v8)를 두고 그때는 날짜 대신 ‘받는 날 미정’으로. 앱 입력 창은 받는 날을 직접 고르니 해당 없음.
- **택배 출고일(v7)**: 택배는 받는 날과 따로 **보내는 날**을 적을 수 있어요. 주문 비서·챗봇에선 `11/21 출고`, `출고 11/21`, `출고일: 11/21(토)`, `내일 발송`. 출고일만 있으면 받는 날도 그날로. 출고일이 받는 날보다 늦으면 알려줘요. **D-day·‘7일 안에 보낼 택배’·아침 알림·정렬은 출고일 기준**(없으면 받는 날) — `src/lib/day.ts` `actDay()`. 예전 DB(v6)에서도 출고일 없는 주문은 그대로 저장돼요(출고일 칸은 값이 있을 때만 보내요). 출고일을 넣으려 하면 ‘DB 업데이트가 필요해요’.
- **먼저 AI 없이 읽어 봐요**(`src/lib/orderParse.ts`, 2026-11-13): 줄마다 `날짜 [요일] [시간] [픽업/택배] 이름 상품 [가격] [(메모)]` 모양이면 바로 등록(여러 줄 한꺼번에), `김포포 보냈어`/`김포포 완료`/`김포포 주문 취소`는 그 이름의 진행 중 주문이 하나면 바로 처리. 날짜는 `11/20`·`11.20`·`11월 20일`·`오늘/내일/모레`. 한 줄이라도 애매하면 메시지 전체를 아래 AI가 맡아요. 요일이 날짜와 다르면 날짜 기준 + 안내.
- 그 밖의 말은 OpenAI(서버 전용, `OPENAI_API_KEY`)에 오늘 날짜(KST)·지금 주문 목록(짧은 번호 #1, #2…)·최근 대화 6줄·새 메시지를 주고,
  **엄격한 JSON**으로 `{reply, actions[]}`를 받아요. action = create / update / complete / reopen / cancel.
- 서버가 검사해서 반영: 날짜 형식 확인, 번호 → 진짜 id, 가격 0 이상, 글자 길이 제한. 실패한 건 `skipped`로 이유를 보여줘요.
- 연도 없는 날짜는 오늘 이후 가장 가까운 날(2달 넘게 지난 날짜면 내년).
- 시간: "오후 3시"→15:00, "3시 반"→15:30, 오전/오후 없는 1~8시는 오후로. 형식이 이상하면 시간만 비우고 주문은 저장. 수정 때 `due_time: ""` = 시간 지우기. AI 답에 빠진 칸은 안 바꿔요.
- 입력 창(직접 추가/고치기): 택배면 ‘받는 날’ 아래 **출고일(선택)** 날짜 버튼 + 지우기. 날짜는 오늘·내일·모레·다음 주 버튼 + 달력, 시간은 오전 10시~오후 9시 버튼 + 정각/15/30/45분 버튼 + 직접 입력·지우기 (`src/components/WhenPicker.tsx`).

## 카카오톡 알림 (`src/lib/server/kakao.ts`, `/api/kakao/*`, `/api/cron/orders`)

- **나에게 보내기** API(`POST https://kapi.kakao.com/v2/api/talk/memo/default/send`, 텍스트 템플릿 200자).
  나와의 채팅방은 **보내기 전용**이라 거기서 주문을 받을 수는 없어요(받으려면 카카오톡 채널 + 챗봇이 필요).
- **보내는 시간은 주문 화면 카카오톡 카드에서 골라요**(한국 0~23시, 기본 9시, `app_settings.brief_hour`, 관리자만). `vercel.json`에 `/api/cron/orders`를 **매시 정각 24개**(각각 하루 한 번 — 무료 플랜 규칙) 등록해 두고, 고른 시각이 되면 그날 한 번만 보내요(`last_brief_on`). 그 시간에 실패하면 다음 시간에 다시 시도. Vercel 무료 예약은 정각~59분 사이에 돌아요. `Authorization: Bearer $CRON_SECRET`이 맞아야만 동작.
- 알림 내용: **택배는 출고일(없으면 받는 날) 7일 전부터 완료할 때까지 매일**(출고일이 있으면 ‘D-2 출고’)(지난 것도), **픽업은 전날·당일**(픽업 시간이 있으면 ‘오늘 오후 3시 픽업’처럼, 시간순). 완료·취소는 빠져요. 보낼 게 없으면 안 보내요. 200자 넘으면 ‘외 N건’.
- 토큰: access는 끝나기 5분 전 자동 갱신, refresh는 카카오가 새로 줄 때 저장(매일 돌면 계속 유지).
- 연결: 관리자 → 주문 화면 ‘카카오톡 연결’ → 카카오 동의 → `/api/kakao/callback`이 토큰 저장(state는 서버 키로 서명, 10분 유효).

### 카카오 디벨로퍼스 설정 (사장님이 한 번)

1. https://developers.kakao.com → 로그인 → **내 애플리케이션 → 애플리케이션 추가** (앱 이름 ‘포포하우스’ 등)
2. **앱 키 → REST API 키** 복사 → Vercel 환경변수 `KAKAO_REST_API_KEY` (Secret)
3. **플랫폼 → Web → 사이트 도메인**에 `https://inhye.vercel.app` 등록 (알림 버튼 링크용)
4. **카카오 로그인 → 활성화 ON**, **Redirect URI**에 `https://inhye.vercel.app/api/kakao/callback` 등록
5. **동의항목 → 카카오톡 메시지 전송(talk_message)** → 선택 동의로 설정
6. (선택) **보안 → Client Secret** 을 ‘사용함’으로 했다면 코드 → Vercel `KAKAO_CLIENT_SECRET` (Secret)
7. Vercel `CRON_SECRET` = 아무 긴 비밀 문자열(영문·숫자 32자 이상 권장, Secret)
8. Redeploy → 앱 **주문 화면 → 카카오톡 연결** → 동의 → **지금 보내 보기**로 확인

메뉴 이름은 카카오 콘솔 개편에 따라 조금 다를 수 있어요.
