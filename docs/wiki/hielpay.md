# 히엘페이 (카드 결제)

- 키오스크 카드 결제를 담당. 홈페이지 https://hielpay.com
- **공개 개발자 API 문서 없음** (2026-10 조사). 홈페이지는 상품 세팅을 “문자·카카오톡·이메일로 요청”하는 방식으로 안내.
- **카드 승인 내역엔 금액만 있고 ‘무슨 상품’인지는 없음** → 재고 차감에는 쓸 수 없고, 빅솔론 판매 데이터가 필요해요.
- 쓸모가 있다면: 정산·카드 매출 합계 엑셀 → 일/월 카드 매출, 수수료 보기 (미구현, 파일 샘플 필요).
- 앱 ‘연동 안내’ 화면(`src/app/(app)/guide/page.tsx`)에 히엘페이 문의 문구가 있어요.
