# 히엘페이 (카드 결제)

- 키오스크 카드 결제를 담당. 홈페이지 https://hielpay.com
- **공개 개발자 API 문서 없음** (2026-10 조사). 홈페이지는 상품 세팅을 “문자·카카오톡·이메일로 요청”하는 방식으로 안내.
- **카드 승인 내역엔 금액만 있고 ‘무슨 상품’인지는 없음** → 재고 차감에는 쓸 수 없고, 빅솔론 판매 데이터가 필요해요.
- 쓸모가 있다면: 정산·카드 매출 합계 엑셀 → 일/월 카드 매출, 수수료 보기 (미구현, 파일 샘플 필요).
- 앱 ‘연동 안내’ 화면(`src/app/(app)/guide/page.tsx`)에 히엘페이 문의 문구가 있어요.

## 빅솔론 없이 우리 앱이 키오스크 판매를 맡는 방안 — 히엘페이 문의 (2026-11-15)

- 사용자 생각: “히엘페이가 결제(PG), 빅솔론은 대시보드·바코드”. 실제 역할: **히엘페이 = 카드 승인**(결제 전문 회사, VAN 서비스·키오스크/포스/단말기 공급·임대 — 이 매장 계약이 PG인지 VAN인지는 미확인), **빅솔론 = 키오스크 판매 프로그램**(바코드 → 상품·가격 찾기 → 장바구니 → 결제 요청 → 상품별 판매 기록). 그래서 상품 등록이 빅솔론이고 상품별 매출도 빅솔론 API에서 와요.
- 우리 앱이 대신하려면: 키오스크용 계산 화면(바코드 담기·합계·결제 버튼), **히엘페이 결제 연동 모듈(SDK/에이전트)**, 영수증·취소·환불, 인터넷 끊김 대비. 상품·가격·바코드·재고는 이미 앱에 있어요. **관건은 히엘페이가 외부 프로그램에 결제 연동을 열어 주는지.**
- 문의 문구: 앱 ‘연동 안내’ 화면 → ‘히엘페이 문의 문구 복사’(`HIEL_ASK`). 묻는 것: ① 키오스크에 다른 프로그램 설치 가능?(OS) ② 결제 연동 모듈·문서·비용 ③ 지금 가맹점 계약 유지·PG/VAN ④ 취소·환불 ⑤ 영수증 프린터·리더기 연결 ⑥ 승인 내역 엑셀/API.
- 같이 확인할 것: 빅솔론 계약 해지 조건·월 이용료, 키오스크 기기 소유(임대·약정).
- 답이 오면: 가능하면 몇 주짜리 작업(매장 기기로 직접 시험 필요), 안 되면 지금처럼 판매는 빅솔론 + 나머지는 앱.
