## AI 기능 (OpenAI, 서버 전용)

- `/api/ai/product`: 상품 사진 → 이름·카테고리·외국어 등 초안 (검토 후 적용)
- `/api/ai/link`: 구매 링크의 상품 페이지를 서버에서 읽어 초안(공개 호스트만, 리다이렉트 재검사, EUC-KR 대응, 1.5MB 제한)
- `/api/ai/promo`: 홍보 글 · `/api/ai/report`: 가게 리포트(숫자는 `src/lib/report.ts`가 계산, AI는 글만)
- 환경변수 `OPENAI_API_KEY`, (선택) `OPENAI_MODEL`. 승인된 직원 이상만 호출.

## 공통

- 체험 모드: Supabase 환경변수가 없으면 IndexedDB에 저장(샘플 데이터, 더보기에서 초기화).
- PWA: 홈 화면에 추가(아이폰 Safari 공유 → 홈 화면에 추가 / 안드로이드 메뉴 → 앱 설치).
- 디자인: 파스텔(berry·soda·butter·matcha·cream), 글꼴 Jua(제목·버튼) + Pretendard(본문), 둥근 카드에 아래 그림자.
