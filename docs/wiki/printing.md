# 라벨 인쇄 · 바코드

## 프린터: Xprinter XP-T4501B

- 뒷면 라벨: `MODEL NO.: XP-T4501B`, `INTERFACE: USB+Cutter`, DC 24V 2.5A → **USB 전용**(블루투스·와이파이·랜 없음).
- XP-T451B 계열: 4인치, 203dpi(1mm = 8점), 명령어 TSPL/EPL/ZPL/DPL.

## 인쇄 방법 3가지 (`/labels`, `/print-station`)

1. **이 기기(브라우저 인쇄)**: PC에 Xprinter 드라이버 → 인쇄 창에서 Xprinter, 용지 크기 선택, 배율 100%.
   - **(2026-11-17) 라벨을 203dpi 그림으로 그려서 인쇄**(`renderLabelImages` → `LabelPrintPortal images`) — USB 직접과 같은 그림이라 라벨을 꽉 채워요. 전엔 화면용 HTML(바코드 굵기·글자 크기 고정)이라 라벨이 커도 가운데에 작게 찍혔어요(사용자 사진으로 확인). 라벨 화면은 그림이 다 그려질 때까지 ‘라벨 그리는 중...’, 인쇄 스테이션도 그림을 먼저 그린 뒤 인쇄, `printNow()`는 그림을 다 읽은 뒤 인쇄 창을 열어요. 미리보기도 같은 그림.
   라벨 크기별 `@page { size: Wmm Hmm }`, A4 21칸·40칸 시트도 지원. 인쇄 영역은 `<body>` 바로 아래 `#print-root` 포털.
2. **USB 직접 (WebUSB + TSPL)**: 안드로이드 크롬 + OTG 젠더, 맥 크롬. 드라이버 불필요, 한글 그대로.
   - 라벨을 203dpi 캔버스로 그림(`src/lib/labelCanvas.ts`) → 1비트 → `BITMAP` 명령(`src/lib/tspl.ts`) → `transferOut`(`src/lib/usbPrinter.ts`).
   - TSPL II 규격: BITMAP 데이터 **0 = 검은 점**, 1 = 빈 칸 (펌웨어가 반대면 ‘흑백 반전’ 설정).
   - 작업 형식: `SIZE w mm,h mm` / `GAP g mm,0 mm` / `DIRECTION d,0` / `REFERENCE 0,0` / `DENSITY n` / `CLS` / `BITMAP 0,0,행바이트,높이,0,<데이터>` / `PRINT 1,매수`.
   - 바코드는 정수 점 굵기(보통 2점 = 0.25mm) + 양옆 빈 공간(약 9모듈). zxing-cpp로 판독 검증함.
   - 기기별 설정(localStorage): 간격, 진하기, 좌우 위치, 위아래 뒤집기, 흑백 반전 + 테스트 라벨.
   - 윈도우는 드라이버가 USB를 잡고 있어 WebUSB가 보통 안 돼요 → 1번 방식. **아이폰은 모든 브라우저가 WebKit이라 WebUSB 불가.**
3. **폰 → 노트북 인쇄 스테이션 (아이폰도 OK)**: 노트북에 프린터를 꽂고 `/print-station`을 띄워 ‘자동 인쇄’.
   - **(v11, 2026-11-17) 인쇄 노트북 등록 + 실시간**: 스테이션에서 ‘이 노트북 등록’(`print_stations`, 이 기기 id는 localStorage `popo.stationId`). 자동 인쇄를 켜 둔 동안 30초마다 `last_seen_at`(‘켜져 있어요’) → 폰의 보내기 화면(라벨 화면 ‘📡 노트북으로’, 상품 ‘노트북으로 보내기’, 새 상품 ‘라벨도 보내기’)에 🟢/⚪ + 노트북 고르기(`StationPicker`, 고른 건 `popo.sendStation`에 기억). 보낸 인쇄는 `print_jobs.station_id` — 노트북은 자기 것 + 노트북을 안 고른 것만 가져가요(`claim_print_jobs(p_limit, p_station)`). 대기열은 **Supabase 실시간**(`watchPrintJobs`, `print_jobs`를 `supabase_realtime`에 넣음)으로 보내는 순간 받아요 — 실시간이 연결되면 20초마다, 안 되면 4초마다 확인. 웹 앱이라 스테이션 창은 켜 둬야 해요(최소화 OK).
   - 폰에서 상품 화면 ‘노트북으로 라벨 보내기’, 라벨 화면 ‘📡 노트북으로’, 새 상품 등록 시 ‘등록하면 라벨도 보내기’.
   - Supabase `print_jobs` 표 + `claim_print_jobs()`(대기→인쇄 중을 원자적으로, 2분 넘게 멈춘 건 재시도) → 두 스테이션이어도 중복 인쇄 없음.
   - 스테이션은 4초마다 확인, 화면 꺼짐 방지(Wake Lock), 완료음, 탭 제목에 대기 수. 인쇄 직전 대기는 rAF 말고 타이머(창이 가려져도 멈추지 않게).
   - 윈도우에서 인쇄 창 없이: Xprinter를 기본 프린터 + 용지 크기 설정, 크롬 바로가기 대상 끝에 `--kiosk-printing`.
   - 체험 모드에선 같은 기기 안에서만 보여요(Supabase 필요).

## 바코드

- 스캔: 폰 카메라(ZXing, EAN-13/8, UPC, CODE128/39, ITF, QR), USB·블루투스 스캐너(키보드 입력, 아무 화면에서 찍으면 그 상품으로 이동 — 입력 화면 제외).
- 같은 바코드가 화면에 계속 있으면 다시 세지 않음(1.2초 이상 사라졌다 다시 찍혀야 +1).
- 바코드 없는 소품: **매장용 EAN-13** `200` + 9자리 일련번호 + 체크디지트(제조사 바코드와 안 겹치는 매장 내부 대역).
- **바코드 라벨 배치(2026-11-17, 사장님 예시 라벨)**: 맨 위 한 줄 ‘이름  가격’(크게) · 가운데 바코드 막대(가로 꽉, 정수 점 굵기) · 아래 바코드 번호(크게, 가운데 — EAN 칸 나눔 없이). 이름·가격이 없으면 막대+번호만. 화면(`LabelFace`)·그림(`renderLabelCanvas`) 같게.
- **라벨이 꽉 안 차고 작게·한쪽에·잘려 나오면(사용자 사진 3장)**: 롤은 대략 2:1(50×25 등). 실제 라벨 한 칸 = 앱 ‘라벨 크기’ = 윈도우 Xprinter ‘인쇄 기본 설정’ 용지 크기(새로 만들기) = 인쇄 창 용지, 여백 없음, 배율 기본. 다르면 크롬이 다른 크기 페이지에 그림을 놓아서 작아지거나 밀려요. 라벨 크기 목록에 40×20 · 50×25 · 60×30 추가, 라벨 화면에 ‘📏 크기 확인용 테스트 1장’(테두리 + 크기 글자)과 맞추는 순서.
- **매장 라벨 = 40×20mm (가로 4cm × 세로 2cm, 사용자 확인 2026-11-17)** → 앱 기본 크기 `DEFAULT_PRESET = "roll-40x20"`(`src/components/labels.tsx`). 예전에 다른 크기를 기억한 기기도 한 번은 40×20으로 바꿔 줘요(`popo.labelPresetDefault`), 그 뒤에 고른 크기는 기억. 윈도우 Xprinter ‘인쇄 기본 설정’ 용지도 40×20(새로 만들기)으로.
- **번호 자릿수(2026-11-17)**: 자동 번호 8 · 10 · 12 · 13자리(기본 13, 이 기기에 기억). 13 = EAN-13 `200`+일련 9+검사, 8 = EAN-8 `2`+일련 6+검사, 10·12 = `2`+일련번호(CODE128). 자릿수마다 따로 세요(`nextStoreCode(existing, len)`, DB는 `storeCodeLike(len)` 모양으로 큰 번호 30개를 보고 셈). 그 자릿수 번호를 다 쓰면 알려줘요.
- **상품 없이 바코드만 만들기 (v10, 2026-11-17)**: 라벨 화면 ‘🆕 상품 없이 바코드만 만들기’(`src/components/BarcodeMaker.tsx`). 빅솔론에 상품을 먼저 등록할 때 바코드부터 만들어 붙여요. 이름·가격은 라벨에 찍을 글(선택, 비우면 바코드만 크게).
  - 만든 번호는 `barcode_issues` 표에 남겨요 → 다음 번호는 **상품 바코드와 만든 번호 중 가장 큰 200… + 1**(`nextStoreBarcode(products, issued)`). 상품 화면·라벨 화면의 ‘매장용 바코드 자동 만들기’도 만든 번호를 피해요. 누를 때 DB에서 가장 큰 번호를 다시 보고, 두 기기가 동시에 누르면(유일 번호 겹침 23505) 다시 계산.
  - **번호 직접 정하기**(숫자·영문·-, 3~30자, `cleanBarcodeInput`) — 이미 있는 상품 바코드·이미 만든 번호면 거절. 13자리 EAN-13·검사 숫자 맞는 EAN-8이 아니면 CODE128로 그려요(검사 숫자 틀린 8자리도 이제 CODE128 — 전엔 EAN-8로 그리다 실패할 수 있었음).
  - **몇 개 만들지**(자동 번호, 1~50개, 번호 각각 다르게 `nextStoreBarcodes`) · **한 개당 몇 장**(1~100) → 만든 바코드마다 그 장수로 인쇄 목록에 담겨요. 여러 개면 ‘번호 모두 복사’(한 줄에 하나).
  - 저장은 `store.issueBarcodes({ name, price, code? | count? })` — 자동 번호는 한 번에 여러 줄 넣고, 겹치면(23505) 다시 계산.
  - **지우기 없음** — 지운 번호가 다시 나가면 이미 붙인 라벨과 겹쳐서.
  - 인쇄: 같은 미리보기·‘N장 인쇄하기’·USB 직접으로. **‘노트북으로’ 보내기는 안 돼요**(인쇄 대기열 `print_jobs.product_id`가 상품에 묶여 있음) → 노트북에서 라벨 화면 ‘최근 만든 바코드’로 바로.
  - 스캔 화면: 상품에 안 붙은 그 번호를 찍으면 ‘상품 없이 만든 바코드예요 · 이름’ 안내 → ‘이미 있는 상품에 붙이기’.
  - 라벨: 이름이 비었거나 가격이 0원이면 안 찍어요(전엔 ‘0원’이 찍혔음) — 화면·USB 그림 둘 다.
