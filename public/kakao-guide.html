처음 한 번: 내 카톡 연결하기

거래처 정보는 가게 사람만 봐야 해서, 포포하우스 앱 계정과 카톡을 한 번 연결해요. 사람마다 자기 계정으로 해요.

  1. 카카오톡에서 포포하우스 관리 채널을 친구 추가해요.
  2. 포포하우스 앱 → 더보기 → 카카오 챗봇 → 연결 코드 받기를 눌러요. 6자리 숫자가 나와요.
  3. 10분 안에 채널 대화방에 처럼 그 숫자를 보내요.
  4. ‘OO님(직원) 계정과 연결됐어요 🎉’가 나오면 끝이에요.

앱 계정이 아직 ‘승인 대기’면 챗봇도 못 써요. 관리자에게 앱 ‘직원 계정 관리’에서 승인해 달라고 해 주세요.

기본 사용법

버튼만 눌러도 되고, 말로 보내도 돼요. 정확한 문장이 아니어도 괜찮고, 이름은 일부만 써도 찾아요.

💡 아래 정해진 말이 아니어도 AI가 뜻을 알아들어요. 예) “도매꾹 전화번호 뭐였지?”, “품절된 거 뭐 있어?”, “곰돌이 남은 거 몇 개야?”, “오늘 얼마 팔았어?”
❓ 방법이 궁금하면 그냥 물어보세요 — “발주 어떻게 넣어?”, “주문 어떻게 넣어?”, “가격 기록 어떻게 해?”

바로가기 버튼이 나와요
할 수 있는 말 목록

주문 (꽃다발 등 예약)

주문은 받은 그대로 보내면 정리해서 등록해요. 여러 건을 한 번에 줄바꿈으로 보내도 돼요.

날짜·시간·픽업/택배·이름·상품·가격을 읽어서 등록 괄호 안 말 (라넌으로 변경) 같은 건 메모로 들어가요
날짜·시간·가격·상품 고치기
완료 처리 완료하면 아침 카톡 알림에서 빠져요. ‘주문 취소’라고 하면 취소돼요
진행 중인 주문을 날짜·시간순으로 7일 안에 보낼 택배가 있으면 알려줘요
그날 찾으러 오는 주문만

날짜 · (요일) · (시간) · 픽업/택배 · 이름 · 상품 · 가격 순서로 쓰면 바로 등록돼요. 이름 보냈어 · 이름 취소도 바로예요. 다르게 쓰면 AI가 읽느라 몇 초 걸리는데, ‘정리하고 있어요 ⏳’ 뒤에 결과가 자동으로 오지 않으면 결과 보기를 눌러 주세요. 같은 주문을 다시 보내도 두 번 등록되지 않아요.

거래처 보기·관리

⭐ 자주 쓰는 곳부터 5곳씩 누르면 그 거래처 정보로 가요. ‘다음 ▶’으로 더 보기
종류·담당자·전화·주문 조건·메모 ‘사이트 열기’ ‘전화하기’ 버튼이 같이 나와요
거기서 사는 상품과 그 거래처 가격·재고 다른 곳이 더 싸면 ‘OO 더 쌈’이라고 알려줘요
하나씩 물어봐요 이름 → 종류 → 사이트 → 담당자 → 전화 → 주문 조건 → 메모. 모르면 ‘건너뛰기’, 다 안 채워도 ‘여기까지 저장’
고칠 칸 고르기 → 새 값 보내기 ‘지우기’로 비우기, ‘자주 쓰는 곳’은 누르면 ⭐ 켜고 꺼요

재고·판매가·원가·마진, 거래처별 가격 그냥 ‘곰돌이’만 보내도 찾아요
바코드 숫자
바코드 번호로 바로 찾기 예: 8801234567893

예시 대화

곰돌이 털 키링 재고 3개 (발주 기준 5개) 판매가 4,500원 · 원가 1,800원 · 마진 60% 거래처별 가격 🏆 1688 1,200원 · 3일 전 • 도매꾹 1,800원 (주) · 1일 전 💡 1688에서 사면 개당 600원 아껴요
다시 주문하기가격 기록앱에서 보기

🏆 = 제일 싼 곳, (주) = 평소에 사는 주 거래처, ‘오래됨’ = 60일 넘게 확인 안 한 가격이에요.

가격 기록하기

같은 물건도 거래처마다, 때마다 값이 달라요. 도매 사이트나 시장에서 가격을 보면 바로 적어 두세요. 나중에 어디가 제일 싼지 알려줘요.

  1. 보내기 (상품 이름 대신 바코드도 돼요)
  2. 거래처 고르기: 버튼을 누르거나 이름을 보내요
  3. 개당 가격 보내기: 1800, 1,800원, 2만, 1만5천 다 돼요
  4. 기록하기를 눌러요. 상품 원가까지 바꾸려면 원가도 바꾸기

예시 대화

1,500원
개당 1,500원으로 기록할까요? (지금 원가 1,800원)
기록하기원가도 바꾸기취소

앱에서 입고 등록할 때 ‘산 곳’과 ‘개당 매입가’를 적으면 가격이 저절로 기록돼요. 따로 안 적어도 돼요.

예시 카드

발주 목록
도매꾹 · 1개 • 곰돌이 털 키링 3/5 → 7개 · 1,800원 ↳ 1688 1,200원 더 쌈 예상 12,600원 🚚 3만원 이상 무료배송
주문하러 가기앱 발주 화면

‘3/5 → 7개’ = 지금 3개, 5개 이하면 발주, 7개 주문 추천이에요. 추천 수량은 앱 발주 화면과 같은 계산이에요.
