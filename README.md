# 포포하우스 · 무인 소품샵 상품관리

무인 소품샵 **포포하우스**의 **상품 · 구매처 · 재고 · 빅솔론 엑셀** 관리 웹앱입니다.
폰에서 쓰기 편하게 만들었고, 홈 화면에 앱처럼 설치할 수 있어요 (PWA).

> “이거 어디서 샀더라?” 를 없애는 게 목표예요. 상품마다 산 곳과 재주문 링크가 붙어 있어서,
> 바코드만 찍으면 바로 **다시 주문하러 가기** 버튼이 나와요.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 상품 등록 | 사진(카메라/앨범, 자동 용량 줄이기), 상품명, 카테고리, 바코드, 매입가·판매가, 메모·태그 |
| 마진 계산 | 원가 입력 시 개당 이익 · 마진율 · 배수 실시간 표시, 추천 판매가(×2 / ×2.5 / ×3) 버튼 |
| 구매처 관리 | 온라인/도매/오프라인 구분, 사이트·담당자·전화·주문 조건. 구매 링크를 붙여넣으면 구매처 자동 연결 (도매꾹, 1688, 알리, 쿠팡 등 인식) |
| 바코드 스캔 | 폰 카메라 / USB·블루투스 스캐너 / 직접 입력. **상품 찾기 · 입고 +1 · 출고 −1** 모드, 되돌리기 |
| 매장용 바코드 | 바코드 없는 소품에 `200…` EAN-13 자동 생성 (제조사 바코드와 안 겹침) |
| 라벨 · 가격표 인쇄 | 롤 40×30 / 50×30 / 60×40 / 직접 입력, A4 21칸 / 40칸. PC 인쇄 창 또는 **안드로이드 USB 직접 인쇄**(TSPL) |
| 재고 · 발주 | 입고/출고/재고맞추기 기록, 품절 알림 기준 → **구매처별 발주 목록**, 카톡으로 목록 공유 |
| 빅솔론 대량등록 엑셀 | 빅솔론 대량작업 양식과 **똑같은 칸·색·서식**으로 내보내기, 가져오기, “빅솔론 반영 필요” 자동 표시 |
| 대시보드 | 판매 중 상품, 평균 마진율, 재고 원가·예상 매출, 이번 달 입고액, 카테고리별 상품 수 |
| 로그인 | 아이디/비밀번호, **자동 로그인**(끄면 이 탭에서만 유지), 관리자/직원 권한, 직원 계정 관리 |
| 백업 | 상품·구매처 전체를 엑셀로 백업 |

## 빅솔론 · 히엘페이 연동 조사 결과

| 연결 | 상태 |
| --- | --- |
| 앱에서 등록·수정 → **빅솔론 대량등록 엑셀** → 빅솔론에 업로드 | ✅ 지금 됨 (양식과 칸·색·서식 동일) |
| 빅솔론 상품 목록 엑셀 → 앱으로 가져오기 (상품 코드 맞추기) | ✅ 지금 됨 |
| 바코드 라벨·가격표 → Xprinter 인쇄 | ✅ 지금 됨 (PC 인쇄 창 / 안드로이드 USB 직접) |
| 빅솔론 **판매내역 엑셀** → 재고 자동 차감 + 매출 통계 | 🟡 샘플 파일을 받으면 추가 |
| 히엘페이 정산 엑셀 → 일/월 카드 매출·수수료 | 🟡 샘플 파일을 받으면 추가 |
| 엑셀 없이 실시간 자동 연동 (API) | 🔴 두 곳 모두 공개 API 없음 → 업체 협조 필요 |

- **빅솔론**: 키오스크(K1 등)·프린터 회사. 상품·매출 데이터용 공개 API/개발자 문서는 찾지 못했어요. 공개 개발 도구는 프린터 인쇄용 **Web Print SDK**뿐이라, 상품은 **대량작업 엑셀**이 공식 연결 통로예요.
- **히엘페이**: 카드 결제. 공개 API 문서 없음. 카드 승인 내역에는 금액만 있고 상품 정보가 없어서, **재고 차감에는 빅솔론 판매내역이 필요**해요.
- 앱의 *더보기 → 연동 안내*에 두 업체에 보낼 문의 문구가 있어요.

## 바코드 프린터 (Xprinter XP-T4501B)

뒷면 라벨 기준 **USB 전용** 모델이에요 (INTERFACE: USB+Cutter). 두 가지로 쓸 수 있어요.

1. **PC + 드라이버** — 라벨 화면 ‘인쇄 창 (PC)’ → 프린터 Xprinter, 용지 크기 선택, 배율 100%
2. **안드로이드 + OTG 젠더** — 크롬에서 라벨 화면 ‘USB 바로 (폰)’ → 연결 → 바로 인쇄.
   브라우저의 WebUSB로 라벨 전체를 1비트 그림(TSPL `BITMAP`)으로 보내서 프린터에 한글 글꼴이 없어도 그대로 찍혀요.
   처음 한 번 ‘테스트 라벨’로 간격·위치·진하기를 맞추면 이 기기에 저장돼요.

아이폰(사파리)은 WebUSB가 없어서 직접 인쇄가 안 되고, 이 모델엔 블루투스·와이파이가 없어요.

## 처음 설정하기 (한 번만)

### 1. Vercel 배포
이 저장소를 Vercel에 연결하면 자동 배포돼요. Supabase를 연결하기 전에는 **체험 모드**(이 기기 브라우저에만 저장)로 동작해요.

### 2. Supabase 연결 (여러 기기에서 같이 쓰기)
- **쉬운 방법**: Vercel 프로젝트 → **Storage** → **Supabase** → Create (지역: Seoul) → 프로젝트에 Connect → **Redeploy**
- **직접 방법**: supabase.com에서 프로젝트 생성 → Project Settings → API 값을 Vercel 환경변수로 등록 → Redeploy

| 환경변수 | 설명 |
| --- | --- |
| `NEXT_PUBLIC_SUPABASE_URL` | Supabase 프로젝트 URL |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | anon(public) 키 (publishable 키도 가능: `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`) |
| `SUPABASE_SERVICE_ROLE_KEY` | 서버 전용 키 — 관리자/직원 계정 만들기에 필요. **절대 공개 금지** |
| `NEXT_PUBLIC_SHOP_NAME` | (선택) 홈 화면 가게 이름 (기본: 포포하우스) |

### 3. DB 만들기
배포된 사이트의 `/setup` 화면에서 **SQL 복사 → SQL 편집기 열기 → Run**.
(파일: [`public/schema.sql`](public/schema.sql) — 여러 번 실행해도 안전)

### 4. 관리자 계정
`/setup` 3단계에서 관리자 아이디·비밀번호를 정하면 바로 로그인돼요.
- **처음 만든 계정이 자동으로 관리자**가 돼요.
- 그 뒤에 누군가 직접 가입해도 **승인 대기** 상태라 아무것도 못 봐요. 관리자가 *더보기 → 직원 계정 관리*에서 승인/생성해요.
- 특정 아이디를 관리자로 바꾸려면 SQL 편집기에서: `update public.profiles set role = 'admin' where username = '아이디';`

## 빅솔론 대량작업 엑셀 칸 대응

| 빅솔론 양식 | 앱 항목 |
| --- | --- |
| 상품 코드 (수정 시에만) | 빅솔론 상품 코드 |
| 상품명 \* / 상품 분류명 \* / 판매가 \* / 사용(Y/N) \* | 상품명 / 카테고리 / 판매가 / 판매 중 |
| 재고 사용(Y/N) / 재고 수량 | 빅솔론 재고 사용 / 재고 (재고 사용 N이면 0) |
| 바코드 | 바코드 |
| 상품단가 | 원가 · 판매가 · 비우기 중 선택 (빅솔론에서 의미 확인 권장) |
| 상품명·설명 (영/중/일) | 외국어 이름 · 설명 |

가져오기는 빅솔론 상품 코드 → 바코드 → 상품명 순서로 같은 상품을 찾아 수정하고, 기존 재고는 기본적으로 덮어쓰지 않아요.

## 개발

```bash
npm install
npm run dev        # http://localhost:3000 (환경변수 없으면 체험 모드)
npm run lint
npm run typecheck
npm run build
```

기술: Next.js 16 (App Router) · React 19 · Tailwind CSS 4 · Supabase (Auth · Postgres RLS · Storage) · TanStack Query · ZXing(카메라 스캔) · JsBarcode · ExcelJS

```
src/
  app/(app)/        로그인 후 화면 (홈, 상품, 스캔, 발주, 구매처, 엑셀, 라벨, 직원, 안내)
  app/login, setup  로그인 / 처음 설정
  app/api/          관리자 계정 생성, 직원 관리 (service role 키 사용)
  components/       UI, 상품 폼, 스캐너, 재고/구매처 시트, 마스코트
  lib/store/        데이터 계층 (Supabase / 체험 모드 IndexedDB)
  lib/excel.ts      빅솔론 대량작업 양식 내보내기·가져오기, 백업
  lib/tspl.ts, labelCanvas.ts, usbPrinter.ts   라벨 그림 → TSPL → WebUSB 직접 인쇄
public/schema.sql   Supabase 스키마 + RLS
```

마스코트 ‘포포’는 이 앱을 위해 새로 그린 캐릭터예요 (저작권 있는 캐릭터 이미지는 쓰지 않았어요).
